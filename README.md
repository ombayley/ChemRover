# 📘 Project Title

> A general project for the comparison of machine learning models

---

## 🧩 Overview

Machine learning is one of the defining technologies of modern software development.
This project uses Python and popular ML frameworks to implement and compare key learning models:
Neural Networks, Random Forests, and Bayesian Optimization.

---

## 🎯 Objectives / Learning Goals

- 🔹 [Goal 1] — Understand the aproaches/philosophies of simple ML libraries (Sci Kit Learn) vs production grade libraries like PyTorch   
- 🔹 [Goal 2] — Get a better understanding of data processing pipelines  
- 🔹 [Goal 3] — Compare ease of building differrent models (e.g. NN vs RF vs BO)  
- 🔹 [Goal 4] — Get a better understanding of each models ability to perform classification and regression tasks.
